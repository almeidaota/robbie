robbie> vamos praticar seu inglês?

Robbie

Um coach de inglês que vive no seu terminal

Conversa como um amigo, corrige sua gramática, rastreia seus erros e pontua cada sessão de forma determinística.

robbie — terminal
$ robbie --help usage: robbie [-h] {activate,setup,show,review,export} ... activate start an interactive coach session setup write your LLM config show dashboard: sessions, ratings, errors per 100 words review spaced-repetition review of your vocab-gap cards export build an Anki .apkg from the vocab cards

01Os cinco comandos

Um assistente de terminal, não um site: tudo roda na sua máquina, os dados ficam com você.

robbie setup

Guarda sua chave da API de LLM em ~/.config/robbie/, com lista de modelos.

robbie activate

O chat de coaching. Corrige, conta suas palavras e encerra com nota + registro.

robbie show

O painel: histórico de sessões, notas, erros por 100 palavras, contagem por tipo.

robbie review

Revisão por repetição espaçada (SM-2) dos seus cards de vocabulário.

robbie export

Gera um pacote .apkg do Anki com todos os cards, offline.

02robbie setup — configuração

Uma vez só: informa a chave da API, o provedor e escolhe o modelo numa lista.

bash
$ robbie setup Writing config to ~/.config/robbie/config.toml LLM API key: ************ API base URL [https://api.deepseek.com]: Select a model: 1. deepseek-v4-flash 2. deepseek-chat 3. deepseek-reasoner 4. custom Model [1-4] (default 1): 1 saved /home/you/.config/robbie/config.toml (chmod 600)
  • Compatível com qualquer API estilo OpenAI: DeepSeek, OpenAI, OpenRouter…
  • Chave nunca vai pro repositório — só via env var ou arquivo local chmod 600.
  • Provedor escolhido automaticamente pela URL base.

03robbie activate — o chat

Você digita normal; o Robbie corrige na hora, no fluxo da conversa, e nunca deixa erro passar (modo casual).

robbie activate — session 2026-08-21-01 · mode casual
you> I'll compete on both gi and no-gi at the tournament. robbie> "Compete on" → "compete in" — prepositions again. "I'll compete in both gi and no-gi." you> But I still didn't decide if I'm ready. robbie> With "still", reach for the present perfect: "I still haven't decided". you> My back is (enferrujado?) after the break. robbie> "Enferrujado" → "rusty". Added to your vocab cards.
  • Streaming estilizado com rich — a resposta chega rolando na tela.
  • Conta suas palavras em tempo real (não é estimativa).
  • Saia com /quit ou apenas diga "let's wrap up".
  • Se o PostgreSQL não estiver no ar, ele sobe via docker compose up -d sozinho.

04No encerramento: fatos + nota

O coach emite o registro da sessão em JSON (validado), e o app calcula tudo de forma determinística.

wrap-up — rating computado pelo código
[italic] wrapping up… rating 7.2/10, 2 errors, 45 words, 4.44 errors/100 words errors: I dont buy nothing → I didn't buy anything (grammar) vocab gaps: atualizar → update I need to (atualize?) my plans vocab cards: 1 gapped pair(s) upserted — try `robbie review`
  • A nota nunca é persistida — é recalculada dos fatos a cada leitura.
  • Erros e lacunas de vocabulário aparecem na tela, sempre.
  • Sessão salva no PostgreSQL + resumo anexado ao log.
  • JSON quebrou? Ele tenta de novo (até 3 vezes).

05Lacunas de vocabulário — "(atualize?)"

Quando você trava no meio da frase e apela pro português, escreva com (?) — o Robbie ensina e a lacuna vira card.

robbie activate — inside a session
you> I need to (atualize?) my plans for the trip. robbie> "Atualizar" → update. "I need to update my plans for the trip." I'll add that one to your cards. Keep going!

Frente do card

atualizar

Verso do card

update
· I need to (atualize?) my plans

No banco

contexto + primeira/última vez + nº de vezes que travou + estado do SM-2

06Modos do coach

Um modo por sessão, escolhido na hora de começar — salvo junto com a sessão para comparar notas por modo.

escolhendo o modo
$ robbie activate --mode formal ╭ session 2026-08-21-02 — mode formal. talk to me. type /quit to wrap up. ╮
casual (padrão)

Conversa como amigo e corrige em toda resposta. Regra dura: nunca deixar erro passar despercebido.

formal

Registro profissional: inglês escrito, deslizes de registro e frases que soam rudes em ocasiões formais.

interview

Entrevista estruturada: um tema, uma pergunta por vez, revisão da sua resposta, ataque aos seus pontos fracos.

07robbie show — o painel

Todo o histórico vira consulta, não contador editado à mão. "Quantos erros de preposição?" é um group by.

robbie show
session date mode words rating err/100w topics -------------------------------------------------------------------------- 2026-08-21-01 2026-08-21 casual 45 7.2 4.44 shopping 2026-08-20-02 2026-08-20 formal 120 8.1 1.67 meeting, report 2026-08-19-01 2026-08-19 interview 98 6.5 3.06 job interview 2026-08-18-01 2026-08-18 casual 63 8.8 0.00 weekend plans -------------------------------------------------------------------------- lifetime counts by type: {'grammar': 14, 'transfer': 9, 'typo': 5, 'style': 2}
erros/100 palavras = erros ÷ palavras × 100. Como a contagem de palavras é feita pelo app, o número é fato, não estimativa.

08robbie review — repetição espaçada

Motor SM-2 próprio (o algoritmo do Anki): vê a frente, tenta responder de cabeça, revela o verso e avalia de Again a Easy.

robbie review — 3 cards due
────────────────────────── atualizar ────────────────────────── (answer any key to reveal)… → update · I need to (atualize?) my plans 2x gapped · learning · interval 3d · ease 2.50 grade: [a]gain [h]ard [g]ood [e]asy (or 1-4), [q]uit → g ────────────────────────── anexar ────────────────────────── done — reviewed 3 of 3 due card(s)
  • Cards atrasados aparecem; intervalos crescem com interval × ease.
  • Cards novos vencem na hora.
  • Avaliação muda o estado SM-2 salvo no card.

09robbie export — Anki sem o Anki

Gera um pacote pronto para importar no Anki — totalmente offline, via genanki.

10A nota, explicada

Nota de 0 a 10, nunca armazenada — recalculada dos fatos da sessão a cada leitura.

nota = clamp( 10 - soma(penalidades), 0, 10 )
Tipo de erroPesoSignificado
grammar1.0estrutura errada
transfer0.6interferência do português → inglês
typo0.3erro de digitação / escorregão
style0.0válido mas não natural — nunca desconta
Exemplo: 5 transferências (5×0.6) + 1 grammar (1.0) + 1 transferência autocorrigida (0.3) + 1 typo (0.3) = penalidade 4.6 → nota 5.4. Erro autocorrigido vale metade do peso — reconhecer o próprio erro merece crédito.
