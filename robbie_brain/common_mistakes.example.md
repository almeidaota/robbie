# Common Mistakes Tracker (example)

Copy this file to `common_mistakes.md`. The coach references these rules by
their number (or a short id) when writing the session wrap-up, and
`robbie rules` syncs them into the database.

## Active Errors

### 1. Preposition mixups (in / at / on / from / into / to / about)
- **Wrong:** "working at my phrases"
- **Right:** "working on my phrases"
- **Times repeated:** 1
- **Notes:** at = point, on = surface, in = container/space.

## Style Preferences (not wrong, just more natural)
